Observation-boundary redaction

Evidence pack · generated 2026-08-02 · synthetic record, no real personal data

The question this answers

When an automated agent reads a page containing personal data, what reaches the language model, and can it be proven afterwards? Filtering the model's output does not answer it: by then the data has already entered the model's context and the transcript. This tool applies the policy before the observation leaves the page.

Limits — stated before purchase, not after

  • This protects against the consumer (the model, the transcript, the logs). It is not a defence against code running inside the page, which by definition already has the DOM.
  • Screenshots are pixels and are not redacted. If a region is sensitive, do not request its image.
  • Matching is literal substring, case-insensitive. It does not infer that "M. Quiroga" is the same person as "Marta Quiroga"; rules are supplied by the operator.
  • Saved reference points contain a non-salted hash of input values. A holder could test a guessed value against one. Treat them as sensitive artifacts.
  • Authenticated pages: this tool uses its own cookie jar and reads the signed-out view. It reports authState rather than pretending otherwise.
